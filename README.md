## 📱 Number Scanner
> **Made by Mostakim Alam**

A web-based OCR (Optical Character Recognition) application designed to scan and extract numbers from images via camera stream or gallery uploads.

### 🔑 Key Features
* **Auto-Scanning:** Real-time auto-capture using live camera stream.
* **Gallery Upload:** Image upload support for saved photos.
* **AI Vision Integration:** Supports OpenAI-compatible APIs (Groq, OpenAI, local Ollama) for enhanced accuracy.
* **Offline OCR Fallback:** Uses Tesseract.js when API keys are not configured.

### 🚀 Usage
1. Open the web app and grant camera permissions.
2. Hold your device steady (10–20cm distance) over the numbers for auto-scan.
3. Alternatively, upload an image directly from your gallery.
4. Configure API credentials in settings for AI-powered vision.
